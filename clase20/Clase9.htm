La pregunta central de hoy

Tenemos $R_{13} \to$ M con $\alpha=0.20$ y $R_{14},R_{18},R_{19} \to$ CB con $\alpha=0.30$, $0.20$, $0.47$.

¿Cómo combinamos estos 4 consecuentes en un único valor crisp $u^*$?

Paso 1: Implicación – Cortar el Consecuente

Método de Implicación por Mínimo (Mamdani)

Para cada regla $R_k$ activa, el conjunto de salida $B^k$ se corta a la altura $\alpha_k$:

\[ \mu_{B'^k}(u) = \min\!\left(\alpha_k,\; \mu_{B^k}(u)\right) \]
$R_{13}$: M cortado a $\alpha=0.20$
$R_{19}$: CB cortado a $\alpha=0.47$ (dominante)

Paso 2: Agregación – Unión de Consecuentes

Método de Agregación por Máximo

Las salidas recortadas de todas las reglas se combinan tomando el máximo punto a punto:

\[ \mu_{agregado}(u) = \max_{k}\!\left(\mu_{B'^k}(u)\right) \]
Agregación de las 4 reglas activas

¿Qué es la Defuzzificación?

Definición

La defuzzificación convierte el conjunto difuso agregado $\mu_{agregado}(u)$ en un valor crisp único $u^*$ que se envía a la planta:

\[ u^* = \mathcal{D}\!\left[\mu_{agregado}(u)\right] \]

donde $\mathcal{D}$ es el operador de defuzzificación.

Métodos principales
  1. Centroide (Center of Gravity) – más preciso
  2. Bisectriz (Bisector) – divide el área en dos
  3. Máximo medio (MOM) – promedio de máximos
  4. Máximo más grande/pequeño (LOM/SOM)
  5. Altura (Height) – suma ponderada de picos
Para sistemas embebidos

El método de altura es el más eficiente computacionalmente: solo requiere sumas y multiplicaciones (sin integración numérica).

El centroide discreto es el más preciso y puede implementarse con un bucle sencillo.

Método 1: Centroide (Center of Gravity)

Fórmula Continua
\[ u^* = \frac{\displaystyle\int_U u \cdot \mu_{agr}(u)\; du} {\displaystyle\int_U \mu_{agr}(u)\; du} \]

Es el centro de masa del área bajo la curva agregada.

Fórmula Discreta (implementación)
\[ u^* = \frac{\displaystyle\sum_{j=1}^{N} u_j \cdot \mu_{agr}(u_j)} {\displaystyle\sum_{j=1}^{N} \mu_{agr}(u_j)} \]

con $N$ puntos uniformes en $[u_{min}, u_{max}]$.

Típicamente $N=100$ puntos

En Arduino: $N=50$ para equilibrio velocidad/precisión.

Método 2: Método de Altura (Singleton)

Idea

En lugar de integrar el área agregada, se usa directamente el pico $c_k$ de cada consecuente ponderado por $\alpha_k$:

\[ u^* = \frac{\displaystyle\sum_{k=1}^{N} \alpha_k \cdot c_k} {\displaystyle\sum_{k=1}^{N} \alpha_k} \]

donde $c_k$ es el centro del consecuente $B^k$.

Método 3: Bisectriz y Máximo Medio

Bisectriz

Divide el área del agregado en dos partes iguales:

\[ \int_{U_{min}}^{u^*} \mu_{agr}(u)\,du = \int_{u^*}^{U_{max}} \mu_{agr}(u)\,du \]
  • Más robusta que el centroide ante asimetrías
  • Más costosa computacionalmente
  • Raramente usada en embebidos
Máximo Medio (MOM)
\[ u^* = \frac{1}{|\Omega|}\sum_{u \in \Omega} u \]

donde $\Omega = \{u : \mu_{agr}(u) = \max\}$

  • Muy rápido: solo buscar el máximo
  • No suave: respuesta discontinua
  • Útil para clasificación, no para control
Recomendación para TCLAB

Usar Centroide Discreto (precisión) o Método de Altura (velocidad). Evitar MOM en sistemas de control continuos.

Paso 4: Defuzzificación por Altura
\[ u^* = \frac{\alpha_{13}\cdot c_M + (\alpha_{14}+\alpha_{18}+\alpha_{19})\cdot c_{CB}} {\alpha_{13}+\alpha_{14}+\alpha_{18}+\alpha_{19}} \]

Verificación: ¿Tiene sentido físico?
  • $e = +7$°C: temperatura algo baja $\to$ necesita potencia
  • $\dot{e} = +1$°C/s: temperatura subiendo $\to$ no aplicar máxima potencia

Comparación con PID clásico (Clase 4)

Un PID con $K_p=2$, $K_d=0.5$: $u_{PID} = 2\cdot7 + 0.5\cdot1 = 14.5\%$

El difuso da $30.1\%$: más agresivo porque sabe que la temperatura todavía está lejos del setpoint. La sintonización difusa se hizo por conocimiento experto, no por fórmulas.

Centroide Discreto: Algoritmo para Implementación

Discretización del Universo de Salida

Se divide $[u_{min}, u_{max}]$ en $N$ puntos equiespaciados:

\[ u_j = u_{min} + j \cdot \frac{u_{max} - u_{min}}{N-1}, \quad j = 0, 1, \ldots, N-1 \]

Para cada $u_j$ se calcula:

\[ \mu_{agr}(u_j) = \max_k \min\!\left(\alpha_k,\; \mu_{B^k}(u_j)\right) \]

Finalmente:

\[ u^* = \frac{\sum_j u_j \cdot \mu_{agr}(u_j)} {\sum_j \mu_{agr}(u_j)} \]

Para sistemas a 100 Hz: usar método de altura para evitar saturar el bucle de control.

Implementación del Centroide Discreto en C++

/**
 * defuzz_centroid() -- Centroide discreto
 * rules:     arreglo de reglas activas
 * n_rules:   numero de reglas activas
 * mf_out[]:  array de N_TERMS MFs de salida (centros)
 * u_min/max: rango del universo de salida
 * N:         numero de puntos de discretizacion
 */
float defuzz_centroid(const ActiveRule* rules, uint8_t n_rules,
                      const float centers[N_TERMS],
                      float u_min, float u_max, uint8_t N) {
    float num = 0.0f, den = 0.0f;
    float du  = (u_max - u_min) / (float)(N - 1);

    for (uint8_t j = 0; j < N; j++) {
        float u_j    = u_min + j * du;
        float mu_agr = 0.0f;

        // Calcular mu_agregado(u_j) = max de cortes
        for (uint8_t k = 0; k < n_rules; k++) {
            // mu del consecuente en u_j (triangular con centro c_k)
            float c   = centers[rules[k].out_idx];
            float span = (u_max - u_min) / (float)(N_TERMS - 1);
            float mu_bk = (span - fabsf(u_j - c)) / span;
            if (mu_bk < 0.0f) mu_bk = 0.0f;
            float cut = fmin2(rules[k].alpha, mu_bk);
            if (cut > mu_agr) mu_agr = cut;  // max
        }
        num += u_j * mu_agr;
        den += mu_agr;
    }
    return (den > 1e-6f) ? (num / den) : (u_max / 2.0f);
}

Implementación del Método de Altura en C++

/**
 * defuzz_height() -- Metodo de altura (singleton)
 * Mucho mas rapido que el centroide discreto.
 * Adecuado para Mamdani con MFs simetricas o T-S.
 *
 * u^* = sum(alpha_k * c_k) / sum(alpha_k)
 */
float defuzz_height(const ActiveRule* rules, uint8_t n_rules,
                    const float centers[N_TERMS]) {
    float num = 0.0f, den = 0.0f;

    for (uint8_t k = 0; k < n_rules; k++) {
        float c = centers[rules[k].out_idx];
        num += rules[k].alpha * c;
        den += rules[k].alpha;
    }
    // Si no hay reglas activas, salida por defecto = 50% (M)
    return (den > 1e-6f) ? (num / den) : 50.0f;
}

// Centros de las MFs de salida [CE, CB, M, AB, AE]
const float OUT_CENTERS[N_TERMS] = {0.0f, 25.0f, 50.0f, 75.0f, 100.0f};
