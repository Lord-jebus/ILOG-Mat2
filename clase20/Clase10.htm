Centroide Discreto Optimizado para AVR

/**
 * Centroide discreto optimizado para AVR
 * Evita recalcular las MFs de salida en cada punto:
 * usa las MFs triangulares con centros fijos conocidos.
 * N: numero de puntos (recomendado 20 para TCLAB a 100Hz)
 */
float defuzz_centroid_fast(const ActiveRule* rules,
                           uint8_t n_rules,
                           uint8_t N) {
    const float U_MIN  = 0.0f, U_MAX = 100.0f;
    const float SPAN   = (U_MAX - U_MIN) / (float)(N_TERMS - 1); // 25%
    float num = 0.0f, den = 0.0f;
    float du  = U_MAX / (float)(N - 1);

    for (uint8_t j = 0; j < N; j++) {
        float u_j    = j * du;
        float mu_agr = 0.0f;

        for (uint8_t k = 0; k < n_rules; k++) {
            float c   = OUT_CENTERS[rules[k].out_idx];
            float dist = u_j - c;
            if (dist < 0.0f) dist = -dist;  // fabsf inline
            if (dist >= SPAN) continue;      // fuera del soporte
            float mu_bk = 1.0f - dist / SPAN;
            float cut   = rules[k].alpha;
            if (mu_bk < cut) cut = mu_bk;   // min inline
            if (cut > mu_agr) mu_agr = cut; // max inline
        }
        num += u_j * mu_agr;
        den += mu_agr;
    }
    return (den > 1e-6f) ? (num / den) : 50.0f;
}

Métricas de Error para Comparar Controladores

Índices de desempeño
IAE - Integral of Absolute Error
\[ \text{IAE} = \int_0^T |e(t)|\; dt \]
Penaliza desviaciones sostenidas.
ISE - Integral of Squared Error
\[ \text{ISE} = \int_0^T e^2(t)\; dt \]
Penaliza errores grandes.
ITAE - Integral Time × Absolute Error
\[ \text{ITAE} = \int_0^T t\cdot|e(t)|\; dt \]
Penaliza errores tardíos.
Área sombreada = IAE

Menor área ⇒ menor IAE ⇒ mejor desempeño.

Cálculo Discreto de las Métricas

Fórmulas discretas

Con muestras $e_k = e(k\Delta t)$, $k=0,1,\ldots,M$:

\[ \text{IAE} \approx \Delta t \sum_{k=0}^{M} |e_k| \] \[ \text{ISE} \approx \Delta t \sum_{k=0}^{M} e_k^2 \] \[ \text{ITAE} \approx \Delta t \sum_{k=0}^{M} k\Delta t \cdot |e_k| \]
Condición de comparación justa

Mismo setpoint, misma condición inicial y mismo tiempo de evaluación $T$ para el PID y el controlador difuso.

Interpretación

Un buen controlador tiene IAE, ISE e ITAE bajos. Si el difuso tiene IAE < PID, gana en estado estacionario.

// Variables de metricas (declarar globales)
float IAE = 0.0f, ISE = 0.0f, ITAE = 0.0f;
float t_ctrl = 0.0f;

// En el loop(), cada ciclo DT:
float e_abs = fabsf(e);
IAE  += e_abs * DT;
ISE  += e * e  * DT;
ITAE += t_ctrl * e_abs * DT;
t_ctrl += DT;

Actividad 2: Control en Tiempo Real con TC-Lab (20–50 min)

Procedimiento
  1. Conectar el TC-Lab al Arduino UNO
  2. Configurar $T_{ref} = 45$°C (alcanzable en ~5 min)
  3. Ejecutar por 10 minutos, registrando por Serial Monitor cada 0.1 s: t, T, e, de, u*, metodo
  4. Guardar el log en archivo .csv
  5. Repetir con el método de altura y el centroide N=20: dos ensayos separados
Si no hay TC-Lab

Usar la planta simulada de primer orden incluida en el sketch. Los resultados son comparables cualitativamente.

Parámetros de referencia
  • $T_{inicial} \approx 25$°C
  • $T_{ref} = 45$°C
  • $\Delta t = 0.1$ s (10 Hz)
  • Duración: 600 muestras (60 s)

Actividad 4: Sintonización Iterativa de Reglas (70–85 min)

¿Qué sintonizar?

Si la respuesta tiene sobreimpulso excesivo:

  • Desplazar la diagonal hacia consecuentes más conservadores (M → CB, AB → M)
  • Modificar las celdas de la diagonal secundaria (comportamiento derivativo)

Si hay error en estado estacionario:

  • Verificar que la celda ZO-ZO → M (50%)
  • Ajustar el centro de la MF de salida M
Metodología de sintonización
  1. Modificar una sola celda de la tabla
  2. Ejecutar 2 minutos en el TC-Lab
  3. Calcular IAE y comparar con la iteración anterior
  4. Si mejora: mantener. Si empeora: revertir.
  5. Repetir con otra celda
Regla de oro

Nunca cambiar más de 3 celdas entre iteraciones. El ajuste fino es incremental.

Análisis de Resultados Típicos

Ventajas esperadas del Difuso
  • Menor sobreimpulso: el comportamiento derivativo en la tabla lo suprime naturalmente
  • Sin windup: no hay integrador
  • No lineal: más agresivo lejos del setpoint, más suave cerca
  • Sin modelo: parámetros interpretables en lenguaje natural
Desventajas típicas
  • Error en estado estacionario: sin integral, puede haber offset permanente
  • Sintonización manual: la tabla de reglas no tiene fórmula sistemática
  • Perturbaciones: el difuso puro (sin integral) responde más lento
