Variables Lingüísticas: Definición Formal

Definición (Zadeh, 1975)

Una variable lingüística $\mathcal{V}$ es una quintupla:

\[ \mathcal{V} = (V,\; T(V),\; X,\; G,\; M) \]
  • $V$: Nombre de la variable (ej: "Error")
  • $T(V)$: Conjunto de términos lingüísticos (ej: {NB, NS, ZO, PS, PB})
  • $X$: Universo de discurso (ej: $[-30, +30]$°C)
  • $G$: Regla gramatical (cómo se forman términos compuestos)
  • $M$: Regla semántica (significado $\to$ función de pertenencia)
Sistema TCLAB – 3 Variables
Variable Términos Universo
Error $e$5$[-30,+30]$°C
Cambio $\dot{e}$5$[-5,+5]$°C/s

Modificadores Lingüísticos

Los términos se pueden ampliar con:

\[ \textbf{muy } A: \mu_{muy\,A}(x) = [\mu_A(x)]^2 \] \[ \textbf{algo } A: \mu_{algo\,A}(x) = [\mu_A(x)]^{0.5} \]

Ej: "muy caliente" vs "algo caliente"

Las Tres Variables del TCLAB

Glosario de términos

CE: Cerrado Extra    CB: Cerrado Bajo
M: Medio    AB: Abierto Bajo    AE: Abierto Extra

Pregunta

¿Por qué la salida va de $0$ a $100$% y no tiene valores negativos?

$\Rightarrow$ La potencia del calentador no puede ser negativa.

Estructura de una Regla IF-THEN Difusa

Forma General (Regla de Mamdani)
\[ R_k:\quad \textbf{IF } x_1 \text{ is } A_1^k \textbf{ AND } x_2 \text{ is } A_2^k \textbf{ THEN } y \text{ is } B^k \]

donde $A_i^k$ y $B^k$ son conjuntos difusos y $k$ es el índice de regla.

IF $e$ is NS AND $\dot{e}$ is ZO
THEN $u$ is AB
Antecedente   →   Consecuente
Componentes clave
  • Antecedente: Condición (premisa): combinación de variables de entrada
  • Consecuente: Conclusión (acción): valor lingüístico de la salida
  • Conectivo: AND $\to$ $\min$    OR $\to$ $\max$

Interpretación Gráfica de una Regla

El Método de Inferencia de Mamdani
\[ \alpha_k = \min(\mu_{NS}(e),\; \mu_{ZO}(\dot{e})) = \min(0{,}53;\; 0{,}60) = 0{,}53 \]

El consecuente $B^k$ se corta a la altura $\alpha_k$ (implicación por mínimo).

Propiedades de las Reglas Difusas

Tipos de conectivos
Conectivo Operación Nombre
AND (estandar)$\min(\mu_A, \mu_B)$Zadeh
AND (producto)$\mu_A \cdot \mu_B$Producto
OR (estandar)$\max(\mu_A, \mu_B)$Zadeh
OR (sumas)$\mu_A + \mu_B - \mu_A\mu_B$Algebraico
En la práctica

El AND por mínimo (Zadeh) es el más usado en control embebido: solo requiere comparaciones, sin multiplicaciones.

Formas de regla

Regla tipo-1 (una entrada):
  IF $e$ is NS THEN $u$ is AB

Regla tipo-2 (dos entradas):
  IF $e$ is NS AND $\dot{e}$ is ZO
  THEN $u$ is AB

Regla con OR:
  IF $e$ is NS OR $e$ is NB
  THEN $u$ is AE

Recomendación de diseño

Usar reglas de dos entradas para sistemas tipo PD difuso (error + cambio de error).

La Base de Reglas: Definición

Definición

La base de reglas $\mathcal{R}$ es el conjunto completo de reglas IF-THEN que define el comportamiento del controlador difuso:

\[ \mathcal{R} = \{R_1, R_2, \ldots, R_N\} \]

Para un sistema con $n_1$ términos en $e$ y $n_2$ términos en $\dot{e}$, el número máximo de reglas es:

\[ N_{max} = n_1 \times n_2 \]

Análisis de la base de reglas

¿Por qué $R_5$ da M en lugar de AE?

Si $e$ es NB (temperatura muy baja) pero $\dot{e}$ es PP (subiendo rápido), aplicar AE podría causar sobreimpulso.

El experto "frena" la acción cuando la tendencia ya está corrigiendo.

Regla de seguridad natural

Las celdas de la diagonal secundaria implementan automáticamente un comportamiento tipo derivativo: anticipan la tendencia de la planta.

Metodología de Diseño: Enfoque del Experto

Pasos para construir la base de reglas
  1. Identificar las variables de entrada y salida
  2. Definir los términos lingüísticos para cada variable
  3. Construir la tabla de decisión caso por caso, preguntando: "¿Qué haría un operador experto en esta situación?"
  4. Verificar la consistencia: no debe haber reglas contradictorias
  5. Completar: toda celda de la tabla debe tener una consecuencia (sin reglas faltantes)
  6. Validar mediante simulación o ensayo
Inconsistencia (a evitar)

$R_a$: IF $e$ is ZO AND $\dot{e}$ is ZO THEN $u$ is AE

$R_b$: IF $e$ is ZO AND $\dot{e}$ is ZO THEN $u$ is CE

$\Rightarrow$ Dos reglas con mismas condiciones y consecuentes opuestos: conflicto.

Completitud (deseable)

La tabla debe estar completamente llena. Celdas vacías implican que en esa región del espacio de estados el controlador no tiene acción definida.

Diseño Guiado: Construir la Tabla Fila por Fila

Criterios de Buen Diseño de la Base de Reglas

Propiedades deseables
  1. Consistencia: sin contradicciones
  2. Completitud: todas las celdas definidas
  3. Continuidad: reglas adyacentes con consecuentes similares (no saltar de CE a CB)
  4. Simetría (si la planta es simétrica): la tabla debería ser antisimétrica respecto al centro (celda ZO-ZO)
Número óptimo de reglas

Más reglas $\neq$ mejor control.

Con 9 reglas bien diseñadas se puede controlar muchos sistemas. Con 49 reglas inconsistentes, el controlador oscilará.

Caso de Análisis 1: Arranque en Frío

Escenario

$T_{ref} = 50$°C,    $T_{actual} = 25$°C

$e = 50-25 = +25$°C $\to$ región PB

$\dot{e} = 0$ (acaba de encender) $\to$ región ZO

Fuzzificación

$\mu_{PB}(25) \approx 0{,}5$    $\mu_{PS}(25) \approx 0{,}5$

$\mu_{ZO}(0) = 1{,}0$

Reglas activadas

$R_{23}$: IF $e$=PB AND $\dot{e}$=ZO THEN $u$=CB
   $\alpha_{23} = \min(0{,}5;\,1{,}0) = 0{,}5$

$R_{18}$: IF $e$=PS AND $\dot{e}$=ZO THEN $u$=CB
   $\alpha_{18} = \min(0{,}5;\,1{,}0) = 0{,}5$

Resultado: alta potencia de calefacción.

Caso de Análisis 2: Aproximación al Setpoint

Escenario

$T_{ref} = 50$°C,    $T_{actual} = 47$°C

$e = +3$°C $\to$ borde ZO/PS

$\dot{e} = +1{,}5$°C/s $\to$ borde ZO/PS

Fuzzificación

$\mu_{ZO}(3) = 0{,}4$,   $\mu_{PS}(3) = 0{,}2$

$\mu_{ZO}(1{,}5) = 0{,}4$,   $\mu_{PS}(1{,}5) = 0{,}4$

4 reglas activadas simultáneamente

$R_{13}$: ZO-ZO $\to$ M,   $\alpha=\min(0.4,0.4)=0.4$
$R_{14}$: ZO-PS $\to$ CB,   $\alpha=\min(0.4,0.4)=0.4$
$R_{18}$: PS-ZO $\to$ CB,   $\alpha=\min(0.2,0.4)=0.2$
$R_{19}$: PS-PS $\to$ CB,   $\alpha=\min(0.2,0.4)=0.2$

El motor de inferencia combina estas 4 salidas. Resultado final: potencia entre M y CB.

Comportamiento esperado

El controlador reduce la potencia gradualmente a medida que la temperatura se aproxima al setpoint, evitando el sobreimpulso.

Esto es equivalente al comportamiento proporcional-derivativo del PD clásico, pero sin necesidad de sintonizar $K_p$ y $K_d$.

Ejercicio Propuesto

Sistema de control de nivel de un tanque

Se desea diseñar un controlador difuso con:

  • Entrada 1: Error de nivel $e \in [-50, +50]$ cm
  • Entrada 2: Tasa de cambio $\dot{e} \in [-10, +10]$ cm/min
  • Salida: Apertura de válvula $u \in [0, 100]$%
Se pide
  1. Definir los términos lingüísticos para cada variable (mínimo 5)
  2. Construir la tabla de reglas $5 \times 5$
  3. Identificar al menos 3 reglas que implementan comportamiento derivativo (anticipación de tendencia)
  4. Verificar que la tabla sea consistente y completa
  5. Para $e = +20$ cm y $\dot{e} = -5$ cm/min, identificar las reglas activas y sus fuerzas de disparo
Pista para el punto 5

$e=+20$ cm activa: PS ($\mu \approx 0{,}5$) y ZO ($\mu \approx 0{,}5$)

$\dot{e}=-5$ cm/min activa: NS ($\mu \approx 0{,}5$) y NN ($\mu \approx 0{,}5$)

Total de reglas activas: $2 \times 2 =$ 4 reglas

Resumen de Conceptos Clave

Lo aprendido hoy
  1. Variable lingüística: nombre, términos, universo, semántica
  2. Regla IF-THEN: antecedente + consecuente
  3. AND: operador $\min$ para combinar antecedentes
  4. Fuerza de disparo $\alpha_k$: nivel de activación de la regla
  5. Base de reglas: tabla $n_1 \times n_2$
  6. Criterios: consistencia, completitud, continuidad, simetría
