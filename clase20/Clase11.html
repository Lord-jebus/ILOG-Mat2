La Pregunta que Nos Hace Takagi y Sugeno

Reflexión histórica

En 1985, Takagi y Sugeno se preguntaron:

"El consecuente difuso de Mamdani requiere defuzzificación costosa. ¿Y si el consecuente fuera directamente una función lineal de las entradas?"

Mamdani – Consecuente Difuso

IF $x_1$ is $A_1^k$ AND $x_2$ is $A_2^k$

THEN $y$ is $\tilde{B}^k$

El consecuente $\tilde{B}^k$ es un conjunto difuso.

Se necesita: implicación + agregación + defuzz.

Takagi-Sugeno – Consecuente Lineal

IF $x_1$ is $A_1^k$ AND $x_2$ is $A_2^k$

THEN $y^k = p_k x_1 + q_k x_2 + r_k$

El consecuente $y^k$ es un número.

Solo se necesita: implicación + suma ponderada.

Takagi, T. & Sugeno, M. (1985). Fuzzy identification of systems and its applications to modeling and control. IEEE Trans. Syst., Man, Cybern., 15(1), 116–132.

Estructura del Modelo T-S

Regla T-S de Orden 1 (la más usada)
\[ R_k:\; \textbf{IF } x_1 \text{ is } A_1^k \textbf{ AND } x_2 \text{ is } A_2^k \;\textbf{THEN }\; y^k = p_k x_1 + q_k x_2 + r_k \]

Los parámetros $p_k,\, q_k,\, r_k$ se llaman consecuentes lineales.

Tipos de reglas T-S

Orden 0 (Singleton):

\[ y^k = r_k \quad \text{(constante)} \]

Equivalente al método de altura de Mamdani.

Orden 1 (Lineal):

\[ y^k = \sum_i p_i^k x_i + r_k \]

Captura la dinámica local del sistema.

Orden 2 (Cuadrático):

\[ y^k = \sum_{i,j} p_{ij}^k x_i x_j + \ldots + r_k \]

Raramente usado en control.

Inferencia T-S

No hay defuzzificación: la salida se calcula directamente como suma ponderada:

\[ y^* = \frac{\displaystyle\sum_{k=1}^N \alpha_k \cdot y^k} {\displaystyle\sum_{k=1}^N \alpha_k} \]

donde $\alpha_k = \mu_{A_1^k}(x_1) \cdot \mu_{A_2^k}(x_2)$ (o con AND-min).

Ventaja computacional
  • Solo sumas y multiplicaciones
  • Sin integración numérica
  • ~5 μs en Arduino UNO

Inferencia T-S: Paso a Paso

Algoritmo de inferencia T-S (Orden 1)
  1. Para cada regla $k$: calcular $\alpha_k = \prod_i \mu_{A_i^k}(x_i)$
  2. Para cada regla $k$: calcular la salida local $y^k = p_k x_1 + q_k x_2 + r_k$
  3. Combinar: $\displaystyle y^* = \frac{\sum_k \alpha_k y^k}{\sum_k \alpha_k}$
Ejemplo con 2 reglas para TCLAB

Datos: $e = +7$°C, $\dot{e} = +2$°C/s, $\mu_{ZO}(7)=0.30$, $\mu_{PS}(7)=0.47$, $\mu_{ZO}(2)=0.20$, $\mu_{PS}(2)=0.80$

Reglas T-S definidas:

  • $R_1$: IF $e$ is ZO AND $\dot{e}$ is ZO THEN $y^1 = 0.5 \cdot e + 0.2 \cdot \dot{e} + 50$    $\alpha_1 = \min(0.30; 0.20) = 0.20$    $y^1 = 0.5(7)+0.2(2)+50 = 54.9$
  • $R_2$: IF $e$ is PS AND $\dot{e}$ is PS THEN $y^2 = 0.8 \cdot e + 0.5 \cdot \dot{e} + 20$    $\alpha_2 = \min(0.47; 0.80) = 0.47$    $y^2 = 0.8(7)+0.5(2)+20 = 27.6$
\[ y^* = \frac{0.20 \cdot 54.9 + 0.47 \cdot 27.6}{0.20 + 0.47} = \frac{10.98 + 12.97}{0.67} = \frac{23.95}{0.67} \approx 35.7\% \]

Interpretación Geométrica de T-S

T-S como Interpolación de Modelos Lineales

Cada regla T-S define un modelo lineal local $y^k = f^k(\mathbf{x})$ válido en la región donde $\mu_{A^k}$ es alta.

La inferencia T-S interpola suavemente entre estos modelos locales según la posición de $\mathbf{x}$.

Analogía con gain scheduling

El gain scheduling clásico cambia bruscamente entre controladores lineales al cruzar un umbral.

T-S hace lo mismo pero de forma suave y continua, usando las MFs como funciones de interpolación.

Velocidad: La Ventaja Clave de T-S en Embebidos

Conclusión

La fuzzificación domina el tiempo en todos los casos (~220 μs). T-S y Mamdani-Altura son casi idénticos en velocidad. La diferencia real de T-S está en la identificación automática de parámetros, no en la velocidad de inferencia.

T-S Orden 0: El Puente entre Arquitecturas

T-S Orden 0 = Mamdani con Método de Altura

Cuando los consecuentes de T-S son constantes $y^k = r_k$, la fórmula de inferencia es idéntica al método de altura de Mamdani:

\[ y^* = \frac{\sum_k \alpha_k \cdot r_k}{\sum_k \alpha_k} \equiv \frac{\sum_k \alpha_k \cdot c_k}{\sum_k \alpha_k} \]

donde $c_k$ es el centro de la MF de salida en Mamdani.

Equivalencia práctica

El controlador difuso de Clase 8-10 implementado con defuzz_height() es un T-S Orden 0 con $r_k \in \{0, 25, 50, 75, 100\}$%

CE=0, CB=25, M=50, AB=75, AE=100

Implicación

No necesitábamos toda la maquinaria de Mamdani (implicación + agregación + defuzz). Con T-S Orden 0 desde el principio habríamos llegado al mismo resultado en menos código.

Regla práctica: Usar T-S Orden 0 cuando el diseño es por experto y la velocidad importa. Usar T-S Orden 1 cuando los parámetros se identifican automáticamente desde datos.

T-S Orden 1: Control Adaptativo Local

Idea Central

Cada región difusa del espacio de entrada tiene su propio modelo lineal del proceso:

\[ y^k = p_k \cdot e + q_k \cdot \dot{e} + r_k \]

Los parámetros $p_k$ son las ganancias locales: $p_k \sim K_p^k$, $q_k \sim K_d^k$.

Control de Motor DC con T-S Orden 1

Para control de velocidad de motor DC con 3 zonas:

Zona$p_k$$q_k$$r_k$
Arranque (error grande)3.50.860
Normal (error medio)2.00.550
Ajuste fino (error pequeño)0.50.145
Ventaja sobre PID clásico

El PID clásico tiene ganancias fijas $K_p, K_d$. El T-S Orden 1 tiene ganancias variables que se adaptan suavemente según la región de operación.

Esto es gain scheduling difuso: la transición entre ganancias es continua y no requiere conmutadores.

Identificación de Parámetros T-S

Método de Mínimos Cuadrados (Lilly, Cap. 5)

Dado un conjunto de datos $\{(\mathbf{x}_j, y_j)\}$, los parámetros del consecuente de la regla $k$ se obtienen minimizando:

\[ J_k = \sum_{j=1}^{M} \alpha_k(\mathbf{x}_j) \cdot \left(y_j - y^k(\mathbf{x}_j)\right)^2 \]

La solución en forma matricial es:

\[ \boldsymbol{\theta}_k = (\mathbf{X}^T \mathbf{W}_k \mathbf{X})^{-1} \mathbf{X}^T \mathbf{W}_k \mathbf{y} \]

donde $\mathbf{W}_k = \text{diag}(\alpha_k(\mathbf{x}_j))$.

Procedimiento práctico
  1. Definir las MFs (partición)
  2. Recopilar datos de entrada-salida del proceso
  3. Para cada regla $k$: resolver el sistema pesado
  4. Verificar que la superficie $y^*(x_1, x_2)$ sea suave y representativa
Se verá en Clase 17-18

La identificación automática de T-S a partir de datos es el tema de la Unidad 3 (Identificación de Sistemas, Clases 17-18).

En Clase 12 usaremos parámetros diseñados manualmente por el experto.

Análisis de Estabilidad mediante Funciones de Lyapunov

Teorema de Estabilidad T-S (Tanaka y Sugeno, 1992)

Un sistema T-S de la forma:

\[ \dot{\mathbf{x}} = \sum_{k=1}^{N} \alpha_k(\mathbf{x}) \cdot \mathbf{A}_k \mathbf{x} \]

es globalmente asintóticamente estable si existe una matriz simétrica definida positiva $\mathbf{P} = \mathbf{P}^T \succ 0$ tal que:

\[ \mathbf{A}_k^T \mathbf{P} + \mathbf{P} \mathbf{A}_k \prec 0 \quad \forall k \]
Significado práctico

Si cada modelo lineal local $\mathbf{A}_k$ es estable y comparte una función de Lyapunov común $V(\mathbf{x}) = \mathbf{x}^T \mathbf{P} \mathbf{x}$, entonces el sistema difuso completo es estable.

Contraste con Mamdani

Para Mamdani no existe un resultado equivalente de estabilidad tan directo. En la práctica, Mamdani se valida por simulación y ensayo.

Esta es una ventaja fundamental de T-S para aplicaciones críticas de seguridad.

Diseño T-S Orden 0 para Control de Motor DC

Sistema

Motor DC con encoder. Variable a controlar: velocidad $\omega$ [RPM].

  • Entradas: Error $e_\omega \in [-300, +300]$ RPM, Cambio $\dot{e}_\omega \in [-100, +100]$ RPM/s
  • Salida: Ciclo de trabajo PWM $u \in [-100, +100]$% (bidireccional)
Tabla T-S Orden 0 (5×5)

Los valores de la tabla son los $r_k$ en %:

$e \backslash \dot{e}$ NNNSZOPSPP
NB -100 -90 -60 -40 -10
NS -90 -60 -40 -10 +20
ZO -20 -10 0 +10 +20
PS -20 +10 +40 +60 +90
PB +10 +40 +60 +90 +100
Características del diseño
  • Salida bidireccional: motor puede ir en ambos sentidos
  • Celda ZO-ZO = 0: sin acción cuando velocidad y tendencia son correctas
  • Tabla antisimétrica: refleja la simetría del motor DC
Diferencia con TCLAB

TCLAB: salida unipolar $[0,100]$%.

Motor DC: salida bipolar $[-100,100]$%.

Implementación T-S en C++ para Motor DC

/**
 * ts_motor.h - Controlador T-S Orden 0 para Motor DC
 * Clase 11 | Velocidad omega in [-300, +300] RPM
 * Salida PWM bidireccional in [-100, +100]%
 */
#include "fuzzy_types.h"
#include "fuzzy_mf.h"

// Tabla T-S Orden 0: valores en % (con signo)
// Fila=error omega (NB..PB), Col=d_error (NN..PP)
// Rango: -100 a +100 (int8_t: -128 a +127, suficiente)
const int8_t TS_TABLE[5][5] = {
    {-100, -90, -60, -40, -10}, // NB
    { -90, -60, -40, -10,  20}, // NS
    { -20, -10,   0,  10,  20}, // ZO
    { -20,  10,  40,  60,  90}, // PS
    {  10,  40,  60,  90, 100}, // PB
};

// Inferencia T-S Orden 0 (suma ponderada)
float ts_infer(const FuzzyDegrees& mu_e,
               const FuzzyDegrees& mu_de) {
    float num = 0.0f, den = 0.0f;
    for (uint8_t i = 0; i < N_TERMS; i++) {
        if (mu_e.mu[i] < 0.001f) continue;
        for (uint8_t j = 0; j < N_TERMS; j++) {
            if (mu_de.mu[j] < 0.001f) continue;
            float alpha = fmin2(mu_e.mu[i], mu_de.mu[j]);
            float r_k   = (float)TS_TABLE[i][j];
            num += alpha * r_k;
            den += alpha;
        }
    }
    return (den > 1e-6f) ? (num / den) : 0.0f;
}

Ejercicio en Clase: Inferencia T-S

Datos

Motor DC. $\omega_{ref}=200$ RPM, $\omega_{actual}=170$ RPM, $\dot{\omega}=+15$ RPM/s.

Usar la tabla T-S Orden 0 de la diapositiva anterior.

Partición de error: NB=$[-300,-150]$, NS=$[-300,-100,0]$, ZO=$[-100,0,100]$, PS=$[0,100,300]$, PB=$[100,300]$.

Paso 1: Variables

$e_\omega = 200-170 = +30$ RPM      $\dot{e}_\omega = +15$ RPM/s

Paso 2: Fuzzificar

$\mu_{ZO}(30) = \frac{100-30}{100} = 0.70$,   $\mu_{PS}(30) = \frac{30-0}{100} = 0.30$

$\mu_{ZO}(15) = \frac{100-15}{100} \approx 0.85$,   $\mu_{PS}(15) = \frac{15-0}{100} = 0.15$

Paso 3: Reglas activas y suma ponderada
  • $\alpha_{ZO,ZO}=\min(0.70;0.85)=0.70$, $r=0$
  • $\alpha_{ZO,PS}=\min(0.70;0.15)=0.15$, $r=+10$
  • $\alpha_{PS,ZO}=\min(0.30;0.85)=0.30$, $r=+40$
  • $\alpha_{PS,PS}=\min(0.30;0.15)=0.15$, $r=+60$
\[ u^* = \frac{0.70(0)+0.15(10)+0.30(40)+0.15(60)}{0.70+0.15+0.30+0.15} = \frac{0+1.5+12+9}{1.30} = \frac{22.5}{1.30} \approx \mathbf{17.3\%} \]

Resumen: Cuándo Usar Cada Arquitectura

Usar MAMDANI cuando...
  • Las reglas las proporciona un experto humano en lenguaje natural
  • La interpretabilidad es prioritaria (certificación, auditoría)
  • No se dispone de datos históricos del proceso
  • Se necesita un prototipo rápido sin modelado
Usar TAKAGI-SUGENO cuando...
  • Se dispone de datos del proceso para identificar parámetros
  • Se necesita análisis de estabilidad formal (Lyapunov)
  • El sistema es de alta frecuencia y la velocidad de inferencia es crítica
  • Se va a implementar gain scheduling suave entre modos de operación
En la práctica industrial: Mamdani para control de procesos con experto disponible, T-S para control de vehículos, robots y sistemas rápidos donde la identificación automática es viable.

Solución Ejercicio – Paso 1 y 2

Paso 1: Cálculo de variables
\[ e_\omega = \omega_{ref} - \omega_{actual} = 200 - 170 = \mathbf{+30\;RPM} \] \[ \dot{e}_\omega = +15\;\text{RPM/s} \]
Paso 2: Fuzzificación

Para $e_\omega = +30$ RPM (en la región ZO-PS):

  • $\mu_{ZO}(30) = \frac{100-30}{100-0} = \frac{70}{100} = \mathbf{0.70}$
  • $\mu_{PS}(30) = \frac{30-0}{100-0} = \frac{30}{100} = \mathbf{0.30}$
  • Verificación: $0.70 + 0.30 = 1.0$ ✓

Para $\dot{e}_\omega = +15$ RPM/s (en la región ZO-PS):

  • $\mu_{ZO}(15) = \frac{100-15}{100} = \mathbf{0.85}$
  • $\mu_{PS}(15) = \frac{15-0}{100} = \mathbf{0.15}$
  • Verificación: $0.85 + 0.15 = 1.0$ ✓

Reglas activas (4 reglas)
ReglaAntecedente$\alpha_k$$r_k$$\alpha_k \cdot r_k$
$R_1$ZO-ZO$\min(0.70; 0.85) = 0.70$00

Suma ponderada (inferencia T-S Orden 0)
\[ u^* = \frac{\sum \alpha_k \cdot r_k}{\sum \alpha_k} = \frac{0 + 1.5 + 12 + 9}{0.70 + 0.15 + 0.30 + 0.15} = \frac{22.5}{1.30} \approx \mathbf{17.3\%} \]
Interpretación

El motor necesita 17.3% de PWM en sentido positivo para alcanzar las 200 RPM. El valor es moderado porque:

  • El error (+30 RPM) es pequeño → acción proporcional baja
  • La velocidad ya está subiendo (+15 RPM/s) → acción derivativa reduce la potencia para evitar sobreimpulso

Verificación Final – Comparación con Mamdani

Equivalencia T-S Orden 0 = Mamdani-Altura

Si hubiéramos usado Mamdani con método de altura y centros de salida:

  • ZO → centro $c = 0\%$
  • PS → centro $c = 25\%$

Con las mismas $\alpha_k$:

\[ u^* = \frac{0.70(0)+0.15(25)+0.30(25)+0.15(25)}{1.30} = \frac{0+3.75+7.5+3.75}{1.30} = \frac{15}{1.30} \approx 11.5\% \]
Diferencia clave

Los valores difieren porque en T-S Orden 0 usamos una tabla específica con valores diseñados para el motor DC (que puede ser bidireccional y tiene diferentes ganancias por región).

En Mamdani-Altura, los centros son fijos (0, 25, 50, 75, 100).

En T-S Orden 0, los $r_k$ pueden ser cualquier valor y se pueden identificar automáticamente.

Conclusión

T-S Orden 0 es una generalización de Mamdani-Altura: cuando los $r_k$ son los centros de las MFs de salida, ambos métodos son matemáticamente equivalentes.
